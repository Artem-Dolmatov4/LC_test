# MLAW RAG

RAG-пайплайн поверх полнотекстовой выгрузки правовых актов города Москвы:
инвентаризация → нарезка → индекс → поиск → оценка.

Контекст проекта, измеренные характеристики корпуса и принятые решения —
в [CLAUDE.md](CLAUDE.md).

## Данные

Ожидается `MLAW_dataset.tar.zst` в корне репозитория (в git не хранится):
28 шардов JSONL по 9 523–9 524 записи, 28 бинарных сайдкаров `.oix`,
`mlaw_manifest.json` и `mlaw_stats.json`. Всего 266 657 записей,
16.94 ГБ в распакованном виде.

Корпус читается **потоком прямо из архива** — распаковывать его на диск не нужно.

## Запуск

```bash
make setup
make test
```

Тесты, которым нужен настоящий архив, пропускаются сами, если его нет:

```bash
make test-slow
```

Весь пайплайн с нуля — инвентаризация → срез → нарезка → индекс → корзина →
оценка → ответы с цитатами:

```bash
make setup && make qdrant && make all
```

Нужны ключи `VOYAGE_API_KEY` и `DEEPSEEK_API_KEY` в `.env` (шаблон — `.env.example`);
Makefile подхватывает их сам.

## Состояние

Готовы все семь шагов, уровень исполнения **L2**: point-in-time поиск по дате,
дедуп выдачи по акту, переранжирование, ответ с программно проверяемыми
цитатами. Отчёт с числами по собственному срезу — [reports/REPORT.md](reports/REPORT.md).

| Модуль | Назначение |
|---|---|
| `src/mlaw/oix.py` | чтение и запись сайдкара `.oix`, доступ по `doc_id`, проверка инвариантов |
| `src/mlaw/stream.py` | потоковое чтение корпуса из `.tar.zst` или из распакованной папки |
| `src/mlaw/inventory.py` | шаг 1 — сплошной проход по банку (266 657 записей за 40 с) |
| `src/mlaw/slice_build.py` | шаг 2 — срез по актам с полными цепочками редакций |
| `src/mlaw/chunk.py` | шаг 3 — трёхуровневая нарезка |
| `src/mlaw/index.py`, `src/mlaw/lexical.py` | шаг 4 — плотный индекс (Qdrant) и BM25 |
| `src/mlaw/basket.py`, `src/mlaw/evaluate.py` | шаг 5 — корзина запросов и оценка с контролями |
| `src/mlaw/search.py`, `src/mlaw/citations.py`, `src/mlaw/answer.py` | шаг 6 — конвейер L2 и ответы с цитатами |

136 тестов, детерминизм сборки среза и нарезки проверен побайтово (sha256).
